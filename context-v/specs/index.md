# Specs

* [Enrich Citations](Enrich-Citations.md) - One command fills in every citation's missing title, author, date, publisher, and brand assets — and shows you every change before it writes.
* [Modal for Pasting LLM Native Content](Modal-for-Pasting-LLM-Native-Content.md) - Stop the parsing problem at the source: a paste-target textarea plus a Google/Perplexity selector, feeding the parser at the cursor.
* [Promote to Canonical Source](Promote-to-Canonical-Source.md) - One command turns a source you'll cite again — a book, a report — into a rich record with its file and full text in your vault.
