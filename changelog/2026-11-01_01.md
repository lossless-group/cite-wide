# The Citation Spec Catches Up With How We Cite

## Why Care?

The Lossless citation spec now matches how we actually cite. Cite Wide is where that spec lives, so anyone writing or generating citations for our content should read this version.

There's nothing to update in your notes. No plugin code changed in this release.

## What's New?

- **The publisher now comes before the title.**
- **`Generated:` joins the format for citations a tool produced.** "Accessed" says a person went to the source. When a tool retrieved it during a run, the citation says `Generated:` with the date of that run and credits the provider last.
- **`Updated:` appears only when it differs** from the published date.

```md
[^F1]: 2019, Sep 10. [PR Newswire](https://www.prnewswire.com/). [Title of the source](url). Updated: 2019, Sep 12. Generated: 2026, Nov 01. [Fireround](https://fireround.dev) API response.
```

Citations a person read keep their `Accessed` date in the existing format.

## Also Since 0.3.1

`context-v/` became an Open Knowledge Format bundle: every doc declares its type, and folders have indexes. Docs also gained the kit's baseline frontmatter, filled from git history.

## Good to Know

Any citation this plugin writes keeps the order it had. Only the written spec changed here, so bringing the plugin's own output in line would be separate work.
